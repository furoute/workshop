# 足球赛前比分预测方法论 ⚽

## 适用场景
任何足球比赛的赛前比分预测：世界杯、欧洲杯、五大联赛（英超/西甲/德甲/意甲/法甲）、欧冠、欧联、亚冠、澳超等。

## 📋 三大步流程

```
📋 三大步流程
│
├── 第一步：查比赛时间（北京时间）+ 国内转播渠道
│   ├── 时间：确认开球时间
│   └── 转播：查国内播出平台
│
├── 第二步：查赔率信息（外网博彩网站最新数据）
│   ├── 胜平负赔率
│   ├── 让球盘
│   └── 大小球
│
└── 第三步：五步分析法 → 得出3个比分预测
```

### 🏆 杯赛模式（世界杯、欧洲杯、美洲杯等）

| 项目 | 说明 |
|:----|:------|
| **小组赛** | 查晋级形势→走战意等级判定（4级），小组末轮关注已出线队轮换 |
| **淘汰赛** | 一场定生死，容错率低，冷门概率升高 |
| **裁判因素** | **必查** — 一场定生死，裁判可能改变比赛走向 |
| **检查表** | 全六步过一遍，尤其关注战意、环境 |
| **比分倾向** | 淘汰赛多小比分（1-0、1-1、0-0），加时/点球可能 |
| **弱旅回归/首参赛** | 首次参赛球队防守意愿超常，警惕系数拉满 |

### 📅 联赛模式（英超、西甲、德甲、意甲、法甲、澳超、中超等）

| 项目 | 说明 |
|:----|:------|
| **当前轮次** | **必查**：`web_search("202X-2X赛季 英超 第X轮 积分榜")` 确认轮次和排名 |
| **积分榜** | 查主客队当前排名、积分、净胜球、近期走势 |
| **主客场** | **必查**：主队主场战绩 vs 客队客场战绩（联赛主客场差距显著） |
| **一周双赛** | 查两队周中是否有杯赛/欧战，体能消耗影响大 |
| **争冠/争四/保级** | 联赛战意看长期目标，不像杯赛一场定生死 |
| **裁判因素** | 一般可不查（联赛漫长，裁判影响平均化），极端情况再查 |
| **比分倾向** | 1-0、1-1、2-1 等常规比分居多，不必特别关注 |
| **防守数据** | 查联赛失球数而非近5场，样本更大更稳定（如"本赛季场均失球数"） |
| **进攻效率** | 查联赛射手榜和球队总进球数 |
| **交手历史** | 联赛历史交锋更有参考价值（同一联赛每年至少碰2次） |

**联赛预测特别注意事项：**
- 🚫 **不要** 查"弱旅首次参赛"、"淘汰赛魔咒"等杯赛专属因素
- ✅ **一定要** 查当前积分榜排名和主客场战绩
- ⚠️ **警惕** 一周双赛带来的轮换和体能问题
- 📉 **联赛平局更常见**，尤其实力接近的球队

### 🔄 混合赛制（欧冠、欧联、亚冠等）

| 阶段 | 规则 |
|:----|:-----|
| **小组赛** | 走**联赛模式**：查积分榜、轮次、主客场、晋级形势 |
| **淘汰赛** | 走**杯赛模式**，但注意：**两回合制**，不是一场定生死 |
| **两回合差异** | 主客场顺序重要，客场进球规则（如适用），次回合加时可能 |
| **联赛夹缝** | 欧冠周中 + 联赛周末 = 一周双赛，查轮换和体能 |

## 第一步：查比赛时间 + 国内转播渠道

### 查北京时间
**搜索模板：** `web_search("队A vs 队B 北京时间")`
- 优先查直播吧/央视/咪咕等国内站（已自动转北京时间）
- **不要用UTC自行换算** — 夏令时、时区转换易出错

### 查转播渠道
按优先级查：直播吧(zhibo8.cc) → 央视(CCTV5) → 咪咕 → 爱奇艺体育 → 懂球帝 → 腾讯 → 抖音

**国内主要平台版权分布：**
| 赛事 | 平台 |
|:----|:-----|
| 英超 | 咪咕、爱奇艺 |
| 西甲/德甲/意甲/法甲 | 咪咕 |
| 欧冠/欧联 | 咪咕、腾讯、爱奇艺 |
| 国家队大赛 | 央视(CCTV5)、咪咕、抖音 |
| 澳超/中超 | 咪咕 |

### 输出格式
```
📅 MM月DD日 HH:MM (BJT) 📍 球场
📺 直播：平台A、平台B
```
无转播则标注：`📺 直播：暂无国内转播`

## 第二步：查赔率信息

必须包含三项：**胜平负赔率 / 让球盘赔率 / 大小球赔率**

搜索英文关键词：`"TeamA vs TeamB odds moneyline"`

### 权威机构列表（按区域）

| 区域 | 机构 | 说明 |
|:----|:-----|:-----|
| 🇺🇸 美盘 | DraftKings、FanDuel、BetMGM、PointsBet | 美盘首选DraftKings |
| 🇬🇧 欧盘 | William Hill(威廉希尔)、bet365、Betfair、Coral、Betfred | 欧盘首选William Hill |

| 🩺 伤停 | SportsMole | 伤停+预测阵容最全 |

## 第三步：五步分析法

### ① 整理赔率
从第二步中提取关键值，记录多源一致点和分歧点。

### ② 看胜负赔率
| 赔率区间 | 含义 |
|----------|------|
| 1.10~1.30 | 大热门 |
| 1.50~2.00 | 优势方，未必稳 |
| 2.00~2.50 | 五五开，爆冷可能 |
| 5.00+ | 纯弱旅 |

### ③ 看让球盘
- ≥1.5：看好大胜，触发深盘爆冷筛查
- 0.5/1：看好赢但不稳
- 0~0.5：势均力敌
- 变盘从深→浅：机构信心下降

### ④ 结合大小球
| 让球+大小球组合 | 含义 | 预测策略 |
|:----|:-----|:---------|
| 让球深 + 大球倾向 | 一致 ✓ | 大胜，大胆预测赢2+球 |
| 让球浅 + 小球倾向 | 一致 ✓ | 沉闷比赛，警惕平局 |
| 让球深 + 小球倾向 | 矛盾 ⚠️ | 小胜（2-0/2-1） |
| 让球浅 + 大球倾向 | 矛盾 ⚠️ | 对攻，大比分平局或冷门 |

### ⑤ 六步主观检查表

| 顺序 | 检查项 | 查什么 | 杯赛 | 联赛 |
|:----:|:-------|:-------|:----|:----|
| ① | **伤停/阵容** | 核心球员是否伤缺/停赛/轮换 | ✅ | ✅ |
| ② | **防守数据** | 杯赛：近5场失球+零封；联赛：赛季场均失球 | ✅ 近5场 | ✅ 赛季数据 |
| ③ | **进攻效率** | 核心射手近期进球效率 | ✅ | ✅ 联赛射手榜 |
| ④ | **战意** | 晋级/复仇/轮换可能 | ✅ 一场定生死 | ✅ 争冠/争四/保级 |
| ⑤ | **近期状态** | 近5场胜率+平局率 | ✅ | ✅ |
| ⑥ | **环境** | 主客场/天气/海拔/时差/一周双赛 | ✅ 场地+天气 | ✅ 主场加成大 |

#### 裁判因素（杯赛淘汰赛必查，联赛一般不查）
| 步骤 | 查什么 |
|:----|:-------|
| a | 姓名、国籍、资历 |
| b | 联赛/洲际赛事执法经验 |
| c | 执法风格（卡牌大师 vs 宽松型） |
| d | 与两队历史执法记录 |
| e | 近期执法表现和争议 |

### 深盘（≥1.5）爆冷筛查清单
1. 弱旅防守数据好（杯赛：近5场场均失球<1或零封≥2场；联赛：赛季场均失球<1）？→ 有能力守住
2. 强队核心射手进球效率低？→ 不能靠名气相信大胜
3. 赔率向弱队方向移动？→ 市场信心下降
4. 弱队擅长防反+强队攻坚存疑？→ 爆冷温床
5. 强队近期赛程密集/已提前晋级？→ 可能轮换收力

### 晋级战意等级判定（适用于小组赛/多赛制）
| 等级 | 条件 | 预测策略 |
|:----:|:-----|:---------|
| 高 | 两队争出线/争头名 | 正常分析 |
| 中 | 已出线但仍有排名动力 | 轻微降级 |
| 低 | 已出线且头名已定 | 警惕冷门 |
| 极低 | 已出线+对手需抢分 | 冷门警报 |

## 国内足彩适配

### 仅让球盘
| 预测比分 vs 让球数 | 推荐 |
|:-------------------|:----|
| 赢2球以上 | 让胜 |
| 刚好赢让球数 | 让平 |
| 赢不够/平/负 | 让负 |

### 有让球和不让球两个选项
- 预测赢2球以上 → 选让盘（博高赔）
- 预测赢1球以内或不确定 → 选不让球保稳
- 让盘赔率需≥2.0才有吸引力

### 输出格式

**简洁版：**
```
## ① 队A vs 队B  MM月DD日 HH:MM

**赔率：** 队A胜X.XX | 让球：队A让X球 | 大小球：O/U X.X
**形势：** （2行简析）
**预测：** 队A X-X / X-X / X-X 队B

**国内足彩：** 让[-2] → 让平 ⭐
理由：预测2-0，让2球=让平
```

**详细版：**
```
## ① 队A vs 队B  MM月DD日 HH:MM

### 📋 基本信息
北京时间、球场、直播平台

### 📊 赔率数据
各来源赔率对比表

### 📈 关键数据
排名、近期战绩、交手历史等

### 🎯 最终预测
方向 | 让球 | 大小球 | 比分（3个）
```
