# 📋 三大步流程（赛前比分预测）

## 第一步：查比赛时间（北京时间）

**铁律：不准用API的UTC时间换算！不能只依赖FIFA初始赛程表！**

**子步骤：**
1. 用 `web_search("2026世界杯 月X日 队A 队B 赛程 北京时间")`
2. 优先来源：央视网(sports.cctv.com)、直播吧(zhibo8.cc)、搜狐/新浪体育
3. 若有多场比赛，汇总成时间表

**输出**：每场比赛的 `📅 MM月DD日 HH:MM BJT` + 📍 地点

---

## 第二步：查赔率信息（外网博彩网站最新数据）

查最权威博彩网站的最新赔率，必须包含以下**三项数据**（缺一不可）：

| 数据项 | 说明 |
|:------|:-----|
| **胜平负赔率 (Moneyline)** | 主胜/平局/客胜 三项赔率 |
| **让球盘 (Handicap/Spread)** | 让球方+让球数+赔率 |
| **大小球 (Over/Under)** | 大/小分界线和赔率 |

**数据来源（推荐顺序）：**
1. DraftKings Sportsbook（ESPN/FOX嵌入）
2. BetMGM
3. Kalshi / Covers.com
4. VegasInsider / bet365

**搜索模板：**
```
web_search("队A vs 队B odds moneyline over under 2026 World Cup")
web_extract 具体赔率页面获取详细数字
```

**输出**：每场比赛三项赔率的汇总表，标注数据来源

## 第三步：五步分析法 → 得出每场3个比分预测

### 第三·一小步：查赔率（整理第二步数据）
从第二步拉到的赔率数据中提取关键值。

### 第三·二小步：看胜负赔率
| 赔率区间(美式→小数) | 含义 |
|:-------------------|:-----|
| -250~-300 (1.40~1.33) | 大热门 |
| -150~-200 (1.67~1.50) | 优势方，未必稳 |
| ±100~-120 (2.00~1.83) | 五五开，爆冷可能 |
| +200+ (3.00+) | 纯弱旅 |

### 第三·三小步：看让球盘
- ≥1.5：看好大胜，但需**立即触发深盘爆冷筛查**
- 0.5/1：看好赢但不稳
- 0~0.5：势均力敌
- 变盘从深→浅：机构信心下降

### 第三·四小步：结合大小球
- Under赔率低(-150~-200) => 看好小比分
- 让球深+大球倾向 => 看好大胜（一致信号）
- 让球深+小球倾向 => 矛盾，谨慎小胜
- 让球浅+小球倾向 => 沉闷比赛

### 第三·五小步：主观因素分析（八步检查表）

| 顺序 | 检查项 | 查什么 |
|:----:|:-------|:-------|
| 1 | **伤停/阵容变动** | 两队核心是否伤缺/停赛/临场换人 |
| 2 | **弱旅近5场防守数据** | 弱旅近5场场均失球数+零封场次 |
| 3 | **强队核心射手大赛效率** | 核心射手近2届大赛场均进球数 |
| 4 | **强队大赛首战历史** | 强队近2届大赛首战是否赢球/赢盘 |
| 5 | **近期状态（尤其平局率）** | 近5场胜率+平局率 |
| 6 | **交手历史** | 首次交手谨慎，历史克制注意 |
| 7 | **战意** | 复仇/关键战/东道主/最后一舞/争金靴 |
| 8 | **环境** | 高温(>28°C)、室内、高原、时差 |

**关键联动规则：**
- 当让球≥1.5时，**立即触发深盘爆冷筛查清单**
- 弱旅近5场场均失球<1 或 零封≥2场 → 警惕系数拉满
- 强队核心射手近2届大赛场均进球<0.3 → 不能靠名气相信大胜

---

### 📦 深盘爆冷筛查清单（让球≥1.5时必查）

```
□ 弱旅首次参赛/时隔多年回归？→ 首战防守意愿超常
□ 弱旅近5场防守数据（场均失球<1？）→ 有能力守住底线
□ 强队大赛首战慢热？→ 降低大胜预期
□ 强队核心射手大赛进球效率低？→ 不能靠名气相信大胜
□ 赔率向弱队方向移动？→ 市场信心下降
□ 弱队擅长防反+强队攻坚存疑？→ 爆冷温床
```

---

### 🎯 最终输出规范

**每场比赛给出2~3个比分**，格式：
```
**预测**：🇦🇷队A X-X / X-X / X-X 🇪🇬队B
方向：队A胜/平局⚠️ | 让球：穿盘/不穿盘 | 大小球：Over/Under X.X
关键信号：（一句话）
```

**比分书写规则：**
- 旗帜emoji在前，国家名在后
- 比分直接写数字，无需每个比分前重复队名

# 📊 赛后复盘

## 🚨 赛后查比分铁律

**绝对不要优先查国外网站！国内网站一眼就能看到最终比分。**

### 正确查询顺序（严格按优先级）
```
第1优先 → 直播吧 (zhibo8.cc)
第2优先 → 懂球帝 (dongqiudi.com)
第3优先 → 央视体育 (CCTV / 央视频)
第4优先 → 咪咕视频
第5优先 → 搜狐/网易/新浪国内媒体
最后手段 → ESPN / FIFA / FOX Sports
```
