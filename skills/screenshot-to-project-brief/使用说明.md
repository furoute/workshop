## 这是什么

用户刷到好项目（短视频/推文截图）后，**截图发给 AI**，AI 自动：

1. **看图** → 提取项目名和线索
2. **搜索找项目主页** → 定位真实 GitHub 地址
3. **核验数据** → 截图数据不可信，必须回源现查
4. **结合环境判断** → 这机器能不能装、该装哪台
5. **出中文简报** → 固定模板

## 怎么装

**技能就是一份 Markdown（带 YAML frontmatter）。**

1. 把 `SKILL.md` 放进你的技能目录（各 agent 位置不同）
2. **按「能力映射」章节，把你的看图/搜索/读网页工具名填进去**
3. 之后遇到"用户发项目截图"的场景，加载它并照流程执行

**依赖**：只需三个通用能力（看图、搜索、读网页）—— 没有别的依赖。

## 四条核心纪律（就算不装技能也请记住）

### 1. 截图里的数据**一律不可信，必须回源现查**

**连技能作者自己的数字都会过时** —— 实测：技能写 53.5k，绒毛核验时已 56k。

**做法**：截图数据只当线索，真实数据从项目页**现读**，简报里**指出差异**。

### 2. 截图里**通常没有** GitHub 地址

别指望截图给 URL。**靠"项目名 + 独特特征词"搜索定位**。

### 3. ⚠️ **同名项目很多，必须验证"是同一个"**

**实测风险**：`VoiceStudio` 真有**至少两个同名 fork**。

**验证三件套**：星数量级 / 描述特征 / **创建时间与最近提交**（蹭热度的 fork 通常很新或长期不更新）。

**⭐ commit 活跃度比星数更可信** —— 星数能注水，commit 不能。

### 4. 光介绍项目没用，要说清"对用户意味着什么"

必答：硬件吃得消吗？该装哪台机器？跟现有工具冲突吗？

## 附：本机环境约束（蓝莓侧的，你按自己情况替换）

| 项 | 值 |
|---|---|
| 上网本 | 4C / 8G / **无独显** / Ubuntu 24.04 |
| 台式机 | 性能够，但**常关** |
| 网络 | 终端**不继承系统代理**，不通外网需走 Clash（`127.0.0.1:7897`） |
| 硬约束 | 用户**明确不要在上网本跑本地大模型** |
| 同机 | 蓝莓（Hermes）+ 蛋糕（OpenClaw）共处一台 |
