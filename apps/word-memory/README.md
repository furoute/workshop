# 🐱 单词猫 — 给女儿的小学英语背单词 App

一款**专为 iPhone 设计**的人教 PEP 小学英语背单词应用，把「背单词」和「云养猫」结合起来：
每背会一个单词，你的猫咪就长大一点、吃得更饱、心情更好。

> 在 iPhone 上用 Safari 打开 → 「添加到主屏幕」，就会像一个真正的 App 一样全屏运行，
> **支持完全离线使用**，不需要 Apple 开发者账号，也不需要上架 App Store。

---

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 🐱 **云养猫** | 5 个成长阶段（猫宝宝 → 小奶猫 → 少年猫 → 成年猫 → 猫大王），饱食度/清洁度/心情会随时间衰减，需要喂食、洗澡、陪玩 |
| 📖 **单元同步** | 人教 PEP 三年级起点 8 册教材，**学到哪、背到哪**，可选整册或单个单元 |
| 🔤 **自然拼读** | 长单词按音节拆分（如 `com · pu · ter`），点击音节单独听、可「拆开拼读」再读整词 |
| 🔁 **智能复习** | 基于遗忘曲线的复习队列，答错的词自动进错题本，按间隔安排再见 |
| 🔥 **每日打卡** | 连续打卡天数、7 天打卡条、12 周热力图 |
| 🪙 **金币奖励** | 答对得金币，可买装扮（蝴蝶结/王冠/围巾/墨镜/魔法帽/金牌） |
| 🏆 **成就徽章** | 12 个成就，从「启程」到「猫大王」 |
| 📊 **家长报告** | 已学/已掌握词数、7 天柱状图、掌握度分布、错题本清单 |
| 🔊 **真人发音** | 用 iOS 自带语音合成，可调语速、切美音/英音，离线可用 |

App **同时内置两个教材版本**，可在「我的 → 教材版本」切换：

| 册 | 词数 | 说明 |

> 2024 新版自 2024 年秋季起从三年级逐年替换（2025 秋四年级、2026 秋五年级、2027 秋六年级），

### 📗 旧版（2012/2013 版）

8 册 46 单元 **913 词**，对照真实教材词表覆盖率 100%。

### 共同特性

- 每个单词包含：**英文 · 音标 · 中文释义 · 音节拆分 · 例句**
- 中文释义经过**儿童化精简**，不使用词典式长释义
- 音节拆分经过专门的切分器处理（`nice` 不切成 `ni-ce`，`grandma` 是 `grand-ma`）

## 🔀 教材版本说明

人教 PEP 小学英语正处改版期，**新旧两版并行**，两版单元标题与词汇完全不同：

| | 📗 旧版 | 🆕 2024 新版 |
|---|---|---|
| 三上 Unit 1 | Hello! | **Making friends** |
| 三上语音板块 | Let's spell | **Letters and sounds**（三下仍叫 Let's spell） |
| Part C | Story time | Story time + **Project** + Reading time |
| 复习单元 | 2 个 Recycle | **1 个 Revision** |
| 全 8 册总单元 | 46 | **54** |

### 怎么判断孩子的课本是哪版

翻到目录页看 **Unit 1**：是 `Making friends` 就是新版，是 `Hello!` 就是旧版。
或看扉页版次：「2024年7月第1版」= 新版。

### 导入其他版本词表

若日后需要补充新版其他年级（或修正数据），准备 TSV/CSV/JSON 后运行：

```powershell
pnpm add:new --check <词表文件>   # 先校验，不写入
pnpm add:new <词表文件>           # 导入并生成 src/data/pep-2024.ts
```

导入器会做完整校验（册 id、单元号、重复词条、释义长度、音节是否拼得回原词），
**任何无法解析的行都会明确报出，绝不静默丢弃**。

## 🚀 怎么装到 iPhone 上

> 📖 详细的图文说明见 **`怎么在手机上打开.md`**

### 前提
iPhone / iPad 和这台电脑连**同一个 WiFi**。

### 步骤

**1. 在电脑上启动服务**

在 `apps/word-memory` 里**双击 `启动单词猫.bat`**，或者运行：

```powershell
cd <project-dir>/apps/word-memory
pnpm serve
```

窗口里会显示**当前正确的网址**和二维码：

```
  📱 在 iPhone / iPad 上用 Safari 打开：

       http://<host-ip>:5273

  或直接扫码：
   ▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄
   █ ▄▄▄▄▄ █▀███ ▀ █
   ...
```

> ⚠️ **IP 会变**：家用宽带重连后地址可能变化。
> 所以每次都用启动脚本看**当前**地址，别记死一个数字。

**2. 在 iPhone / iPad 上打开**

用 **Safari**（一定是 Safari，微信 / Chrome 不行）访问上面显示的网址。

**3. 添加到主屏幕**

- **iPhone**：点底部**分享按钮**（□ 里有个 ↑）→ 向下滑 → **「添加到主屏幕」**
- **iPad**：分享按钮在**顶部工具栏** → **「添加到主屏幕」**（带 ➕ 的方框图标）

**4. 完成！**

主屏幕上会出现单词猫的图标。以后点它就能直接全屏打开，
**没有浏览器地址栏，和原生 App 一模一样**。

> 💡 **离线也能用**：第一次打开后，所有内容（包括猫咪图片）都会缓存到手机上。
> 之后就算不开电脑、没有网络，也能正常背单词。

### 打不开了？

| 现象 | 原因 | 解决 |
|---|---|---|
| 一直转圈 | 服务没开 | 重新双击 `启动单词猫.bat` |
| 突然连不上 | **电脑 IP 变了**（最常见） | 重新启动脚本，看新网址 |
| 手机连不上 | 手机没连同一个 WiFi | 检查手机 WiFi 设置 |
| 找不到"添加到主屏幕" | 用的不是 Safari | 换 Safari 打开 |
| 弹防火墙提示 | Windows 首次拦截 | 点「允许」 |

## 🛠 开发

```powershell
pnpm install        # 安装依赖
pnpm dev            # 开发服务器（热更新）
pnpm build          # 生产构建
pnpm serve          # 构建 + 启动，自动显示网址和二维码（给 iPhone 用这个）
pnpm check          # TypeScript 类型检查
pnpm verify         # 无头浏览器自动化验收（27 项）
pnpm verify:ios     # iPhone 安装路径 + 离线能力验收（14 项）
pnpm diagnose       # 答题流程诊断（出问题时用）
pnpm vocab          # 词库覆盖度校验
pnpm icons          # 重新生成 App 图标
```

### 技术栈

- **Vite 5 + TypeScript**，零运行时框架（手写模板渲染），包体极小
- 生产产物：**JS 124KB（gzip 52KB）+ CSS 20KB**，iOS 上秒开
- **PWA**：manifest + Service Worker，缓存优先，离线可用
- 数据存在 `localStorage`，**完全本地**，不上传任何信息

## 🔍 开发过程中发现并修复的问题

| 问题 | 原因 | 修复 |
|---|---|---|
| 点「下一个」按钮完全无反应，进度卡在 1/10 | 反馈条挂在 `document.body` 上，而事件监听只绑在 `#app`，点击事件到不了处理函数 | 监听改绑到 `document` |
| `pep6a` 的 `hobby` 重复定义 | 词库两条同名记录导致 id 冲突 | 删除重复项 |
| `pep4b` 的 `sweater` 音节拼不回原词 | 音节拆分错误 `['wea','ter']` | 改为 `['swea','ter']` |
| `pep4b` 的 `teachers office` 与 `teacher's office` 撞车 | 归一化后重复 | 保留原条目，撤回新增 |
