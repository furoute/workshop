# 📱 怎么在 iPhone / iPad 上打开

## ⚡ 最简单的方式

在 `apps/word-memory` 文件夹里，**双击 `启动单词猫.bat`**。

会弹出一个黑窗口，里面显示：

```
  ══════════════════════════════════════════════════
     单词猫 — 小学英语背单词
  ══════════════════════════════════════════════════

  [1/3] 依赖已就绪
  [2/3] 构建中...
        构建完成
  [3/3] 正在获取本机当前地址...

  ══════════════════════════════════════════════════

   📱 在 iPhone / iPad 上用 Safari 打开：

        http://<host-ip>:5273          ← 这个地址每次可能不同

   打开后点「分享」→「添加到主屏幕」
   就会变成一个真正的 App，可离线使用

   或直接扫码：

   ▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄
   █ ▄▄▄▄▄ █▀███ ▀ █
   ...
```

**手机直接扫这个二维码**，或者手动输入上面的网址。

> ⚠️ **这个黑窗口不要关闭** —— 关掉服务就停了。

---

## 🔄 关于网址会变（重要）

**电脑每次重启或重新连 WiFi，网址很可能会变**，比如：

- 地址由路由器的 LAN 网段决定
- 重连后尾号可能变化

这是家用宽带的正常现象（路由器动态分配地址），不是 App 的问题。

### 怎么办？很简单

**每次要用的时候，都双击一次 `启动单词猫.bat`**，
它会自动检测当前 IP 并把**最新的网址**显示出来。

你不需要记任何数字，看一眼窗口、或者直接扫码就行。

### 之前加到主屏幕的图标打不开了？

因为地址变了。处理方法：

1. 双击 `启动单词猫.bat`，看新地址
2. 手机上**长按旧图标 → 删除**
3. 用新地址重新「添加到主屏幕」

> 💾 **学习记录不会丢** —— 数据存在手机本地，跟网址无关。

## 📲 添加到主屏幕（变成真正的 App）

**iPhone：**
1. 用 **Safari** 打开网址（微信里打开的不行）
2. 点底部中间的**分享按钮**（方框里有个 ↑）
3. 向下滑，点 **「添加到主屏幕」**
4. 点「添加」

**iPad：**
1. 用 **Safari** 打开网址
2. 点**顶部工具栏**的分享按钮（iPad 的分享按钮在上面，不在下面）
3. 找到 **「添加到主屏幕」**（带 ➕ 的方框图标）
4. 点「添加」

完成后主屏幕会出现猫咪图标，点开是**全屏无地址栏**的，和原生 App 一样。

## ❓ 打不开的排查顺序

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击 bat 一闪而过 | 需要看错误信息 | 改用下面的「手动启动」看报错 |
| 窗口显示"没有找到局域网地址" | 电脑没连网 | 检查电脑的 WiFi / 网线 |
| 手机一直转圈 | 服务没开 | 重新双击 `启动单词猫.bat` |
| 昨天能开，今天不行 | **网址变了**（最常见） | 重新双击 bat，看新地址 |
| 手机连不上 | 没连同一个 WiFi | 手机 WiFi 要选**和电脑同一个** |
| 找不到"添加到主屏幕" | 用的不是 Safari | 换 Safari 打开 |
| 弹防火墙提示 | Windows 首次拦截 | 点**「允许」**（误点取消见下） |

### 防火墙误点了「取消」

去 `Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙`，
找到 **Node.js**，把「专用」和「公用」都勾上。

### 手动启动（bat 出问题时）

打开 PowerShell，运行：

```powershell
cd <project-dir>/apps/word-memory
pnpm serve
```

效果和双击 bat 完全一样。

## 💾 关于数据

- 学习记录存在**手机本地**，不上传任何服务器
- iPhone 和 iPad 的记录**各自独立**，不互通
- 换手机不会同步，可用「我的 → 导出学习数据」备份
- 主屏幕图标删了重加，**记录不会丢**
